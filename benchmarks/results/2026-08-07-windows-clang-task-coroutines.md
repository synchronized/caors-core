# Windows Clang 任务协程基准

## 环境与方法

- 日期：2026-08-07；
- 分支：`feature/asio-task-redesign`；
- preset：`windows-clang-benchmark`，Release；
- 每个场景执行 100,000 轮，完整程序独立运行三次；
- 延迟以 16 次操作为一批，每轮采集 6,250 个样本；
- 分配统计只覆盖 request 的 `memory_resource`，不包含全局分配器创建的协程帧。

## 分配结果

| 场景 | 总分配次数 | 每轮分配次数 | 每轮累计分配字节 | 峰值存活字节 | 结束时存活字节 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 请求已完成 | 1 | 0.00001 | 0.0016 B | 160 B | 0 B |
| 单等待者 | 300,000 | 3 | 232 B | 232 B | 0 B |
| 四等待者 | 900,000 | 9 | 592 B | 520 B | 0 B |

ready 场景唯一一次分配来自预先创建并复用的 request 状态；100,000 次等待不创建辅助状态。

## 延迟结果

单位为 ns/操作；表中保留三次独立运行结果。

| 场景 | 第一次 p50 / p95 / max | 第二次 p50 / p95 / max | 第三次 p50 / p95 / max |
| --- | ---: | ---: | ---: |
| 请求已完成 | 106 / 112 / 981 | 106 / 112 / 4,743 | 106 / 112 / 3,781 |
| 单等待者 | 400 / 418 / 5,150 | 400 / 418 / 6,231 | 393 / 412 / 4,650 |
| 四等待者 | 1,325 / 1,418 / 51,343 | 1,343 / 1,400 / 8,606 | 1,325 / 1,381 / 55,525 |

## 结论

- ready 路径已消除每次等待的辅助状态分配，p50/p95 稳定在 106/112 ns；
- 单等待者稳定为每轮 3 次请求资源分配，p50 为 393–400 ns，p95 为 412–418 ns；
- 四等待者稳定为每轮 9 次请求资源分配，p50 为 1,325–1,343 ns，p95 为 1,381–1,418 ns；
- 最大值受系统调度抖动影响明显，回归判断应优先使用 p50/p95；
- 该 microbenchmark 只建立当前基线，真实调度器和业务 workload 仍需独立复验。
