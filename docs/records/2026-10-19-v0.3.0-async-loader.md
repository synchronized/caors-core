# v0.3.0 异步 loader 执行记录

## 范围与状态

日期：2026-10-19；分支 feature/v0.3.0-async-loader；范围见[v0.3.0](../versions/v0.3.0.md)。
实现已进入集成验收，尚未发布。最终代码 SHA 与 CI 证据在执行后补齐，不用旧版本结果替代。

## 已执行

Windows x64 / Clang 23.1.1 / MSVC ABI，使用全新目录 build/v030-clang-debug。
资源异步、database 与 asset_manager 三组专项 CTest 通过，新资产组涵盖延迟完成、拒绝/丢弃、
共享取消与首次调度、迟到回调、progress 保活、混合预加载、协程、跨线程回调、重配与工厂。
取消与回调竞争每轮包含 32 次；安装包仍为六类 consumer，资源 coroutine consumer 扩展到原生异步/group。
Clang Shared Debug 原始及迁移前缀各 6/6 consumer 通过（build/v030-clang-package.log）。

单次分配故障注入发现 loading 状态更新的异常在启动保护范围外，已扩大保护并确认请求收到 out_of_memory，
没有遗留真实操作计数。完成回调还覆盖了重入释放完成凭证所属对象，内部局部保活避免悬空。

Windows MSVC Debug 的三组专项 CTest 也已通过（build/v030-msvc-test.log）。
公共头/示例/完整回归、必要重复测试，以及完整批次的 Linux 5 / Windows 3 CI 正在准备或执行。

## 限制

示例和测试使用自有模拟 I/O，未执行真实 libuv 或 Gneiss 联合构建，不宣称已完成其接入。
loader、allocator、模块 pin、宿主 loop 与执行环境由宿主保证寿命，group 不延长 manager 的存活时间。
只承诺现有无异常头编译探针，尚非完整无异常运行验证；没有新后端吞吐或长期运行性能保证。
