## 风险与未验证项

Gneiss 尚未更新依赖锁定并运行其宿主/业务 Web 测试；用户已确认本次交付限于 CAORS 独立平台，
因此不阻塞本次发布，但仍阻塞上游删除临时资源开关或宣称联调通过。恢复条件见关联 Plan。
pthread、动态插件、WASI、wasm64 不在 Web 承诺范围。完整无异常运行、稳定 C++ ABI 和生产性能未承诺。
公共类型布局变化，须统一重编译库与使用方。固定 Linux 性能复验沿用既有延期，不承诺性能改善。
新增快照回退与 I/O 终态释放涉及生命周期，最终 SHA 已通过 Linux Stress；结果不能替代固定环境性能验收。
首次测试/基准需联网或预填开发依赖缓存，浏览器驱动还需 npm ci，见接入与依赖指南。
