# v0.7.0 发布验收

## 范围与状态

2026-10-21 用户授权发布 [v0.7.0](../versions/v0.7.0.md) alpha 源码，限定 CAORS 独立 Emscripten
wasm32 单线程静态平台及既有 Windows/Linux；不包含预编译 SDK。当前为候选验收中，尚未创建标签。
功能集成证据见[平台记录](2026-10-20-emscripten-integration.md)，不替代最终发布提交验证。

## 提交与验证

从 origin/main 5830569c 创建 release/0.7.0，仅收口版本与文档；版本准备 PR 合并后冻结最终 main SHA。
最终提交执行 Linux5、Windows3、Web1；Web 包含浏览器、Node、公共头与安装迁移，原生包含 sanitizer、
六类安装 consumer 与迁移部署。干净工作树和源码归档另核对版本、联网冷配置及预填缓存离线构建。
最终 SHA、运行链接及制品摘要先记录于发布 manifest，公开后回写，避免改变冻结提交。

## 风险与未验证项

Gneiss 尚未更新依赖锁定并运行其宿主/业务 Web 测试；用户已确认本次交付限于 CAORS 独立平台，
因此不阻塞本次发布，但仍阻塞上游删除临时资源开关或宣称联调通过。恢复条件见关联 Plan。
pthread、动态插件、WASI、wasm64 不在 Web 承诺范围。完整无异常运行、稳定 C++ ABI 和生产性能未承诺。
公共类型布局变化，须统一重编译库与使用方。固定 Linux 性能复验沿用既有延期，不承诺性能改善。
新增快照回退与 I/O 终态释放涉及生命周期，最终 SHA 补 Linux Stress；结果不能替代固定环境性能验收。
首次测试/基准需联网或预填开发依赖缓存，浏览器驱动还需 npm ci，见接入与依赖指南。
