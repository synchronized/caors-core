## 标准库调度后端范围调整

2026-10-19 用户确认删除 Asio，内置 thread_pool 改为标准库线程、条件变量与 FIFO 队列，
execution_context 保留调用线程驱动。协程入口改为 `caors/tasks/coroutine.h`。
本节之前的 CI、Windows 矩阵和性能证据均针对旧后端，不能作为本轮新实现的最终验收。

新实现的任务节点与 worker 数组使用长期内存资源，空队列、清空及取消关闭不分配新节点；
标准库线程与同步原语的系统内部资源不受该资源统计。构造线程失败清理已创建线程，
任务执行及捕获对象销毁在队列锁外。池内任务禁止阻塞关闭自身线程池。

已新增并发提交/并发 drain 关闭、任务异常隔离、清空析构回调重入、run 耗尽与重启测试。
本轮全新 Windows 八组、完整 Linux CI、重复测试及安装迁移已通过，结果统一见本页“当前实现验收结论”。
