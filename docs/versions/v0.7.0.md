# v0.7.0：Emscripten 单线程平台接入

## 状态

已发布 alpha；2026-10-21 按 CAORS 独立平台范围公开源码。
工程版本为 0.7.0；最终提交验收见[发布记录](../records/2026-10-21-v0.7.0-acceptance.md)。
评估时 main 的 Emscripten 5.0.6 无 pthread 编译失败，见[评估记录](../records/2026-10-20-emscripten-assessment.md)；
开发分支已修复首批阻塞，实际验收进展见[集成记录](../records/2026-10-20-emscripten-integration.md)。

## 固定范围与非目标

以 wasm32、Emscripten 5.0.6、单线程静态库作为首个验证基线，保留 Windows/Linux 原生契约。
解决共享快照标准库兼容、32 位哈希诊断和后续编译/链接阻塞；提供独立 preset、安装 consumer、
Node 协议测试及真实浏览器异步 smoke。宿主使用现有 executor 驱动，不自动创建后台线程。

不纳入 pthread/SharedArrayBuffer、Web Worker 线程池、Wasm 动态链接插件、WebGPU、WASI、wasm64，
不提供 Gneiss URI/场景/RID/资产格式，也不把 fetch、libuv 或浏览器循环绑定到核心库。
这些是首版承诺边界，不意味着所有其他模式都无法使用。

## 关联计划与依赖

- [Emscripten 单线程平台接入](../plans/emscripten-single-thread-platform.md)：按批次解决构建、调度、运行、安装与回归。
- 上游需求来源：Gneiss 的 UPSTREAM-051-caors-web-convergence.md；实际核对内容与 Granit 参考入口由评估记录维护。
- 现有异步 loader、executor、资源请求和 VFS 快照是接入基础，不另造 Web 专用加载协议。

## 交付契约与兼容

本次公开交付源码归档、manifest 与 SHA256SUMS，不提供预编译 SDK。源码支持生成可安装静态 CMake 包；emscripten-static-debug/release 已提供并通过独立平台集成验收。
默认原生动态库行为不变，Web 不模拟原生共享库或动态插件。任何公共头布局变化需在 CHANGELOG
说明宿主与插件统一重编译，内部抽象不得被描述为稳定 C++ ABI。

## 发布门槛

完整静态库、独立公共头、安装和迁移 consumer 通过；Node 完成确定性协议测试，浏览器实际跨事件循环
执行加载、取消/关闭与迟到回执测试；原生快照并发读写和旧引用保活通过，并完成受影响的 Linux5/Windows3。
不能以 Node 通过代替浏览器验证，也不能以生成 .a 代替最终消费端链接与运行。
Gneiss 联合验收明确排除在本次发布范围之外，不阻塞 CAORS 独立平台源码发布。
上游尚未更新锁定提交并完成其宿主/业务 Web 验证；恢复条件及删除临时开关的门槛见关联 Plan。
发布说明不得宣称 Gneiss 集成已经通过。
