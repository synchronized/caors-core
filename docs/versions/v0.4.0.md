# v0.4.0：统一 VFS 与异步范围读取

## 状态

已发布且公开下载复核通过，alpha；发布日期为 2026-10-20。
工程版本由 [caors_version.cmake](../../cmake/caors_version.cmake) 统一维护。
[GitHub Release](https://github.com/synchronized/caors-core/releases/tag/v0.4.0)交付源码、manifest 和校验和，
不包含预编译 SDK；最终 SHA 与证据见开发记录。

## 固定范围

交付 CAORS 源码和可安装 CMake 包：同一挂载体系下的拥有式路由快照、可选异步打开、精确随机范围读取、
拥有式结果、取消/完成投递/关闭协议、预算与诊断、资源来源转发，以及模拟后端和 loader 示例。
既有同步借用接口保留；新增 ABI/布局要求宿主及插件统一重编译，不承诺旧 DLL 兼容。
已确认设计及任务唯一入口为 [统一 VFS 计划](../plans/asynchronous-vfs.md)。

| 批次 | 出口 |
| --- | --- |
| VFS-01 | 后端所有权、不可变路由及嵌套快照、来源身份与并发规则 |
| VFS-02 | 异步请求、打开/精确范围读取/关闭、显式同步适配与错误/预算 |
| VFS-03 | source/provider/loader 贯通及安装示例，不重复实现资源缓存 |
| VFS-04 | 跨平台集成验收、文档与固定提交交接 |

不包含 CAORS 内置 libuv、异步写入/枚举/监听、网络/压缩包后端、全局调度预算、GPU 发布、
场景事务、稳定 C++ ABI、正式环境吞吐或完整无异常运行保证。
Gneiss 的 libuv 后端与资产迁移独立实施，不因本版完成而宣称整套资产迁移完成。

## 发布门槛

四批任务和计划内集成矩阵已通过；最终发布提交同样通过：同步兼容、范围约束、后端/模块寿命、快照并发、共享/取消与关闭无退化。
完整批次运行 Linux 5 / Windows 3 常规 CI，必要压力、公共头与原始/迁移安装 consumer 通过。
详细实际结果只写 [开发记录](../records/2026-10-19-v0.4.0-async-vfs.md)。
Gneiss 联合验证必须如实记录范围；没有环境时不扩大接入声明，发现协议缺陷必须先修复。
功能与版本准备均已合入 main，并按 [发布流程](../guides/release.md) 固定最终 SHA、完成本版 CI 和制品复核；
不复用 v0.3.0 的历史 CI 充当本版验收。
