# 发布验收清单

本页维护每个版本必须检查的条件；执行顺序见[发布流程](../guides/release.md)，
实际结果写入版本 Record，不在本清单勾选历史结果。没有工具支持的项由维护者执行，不能推断已自动完成。

## 身份与范围

- [ ] 固定版本范围、非目标、交付形式与承诺平台，所有关联 Plan 明确实际完成与延期。
- [ ] CMake 源版本、生成版本常量、运行时查询、包版本和标签命名一致。
- [ ] 最终 main SHA 已固定，工作树干净；验证后没有悄悄切换到新的分支头，标签未使用。
- [ ] CHANGELOG 版本章节非空，破坏性变更和用户需要执行的迁移操作明确。
- [ ] 候选验收状态与“已发布”状态区分，未验证内容及其对本次范围的影响明确。

## 正确性与安装

- [ ] 最终 SHA 完成 CI 策略规定的 Windows 常规矩阵；Debug/其他组合按版本承诺及变更风险补充。
- [ ] 最终 SHA 完成 CI 策略规定的 Linux 常规矩阵，包括两种编译器、静态/动态、ASan/UBSan。
- [ ] 插件、临时内存或 MessagePack 高风险变化完成相应重复压力验证。
- [ ] 静态/动态安装、六类 consumer、迁移前缀、动态库运行时部署和私有依赖边界通过。
- [ ] 公共头、相关示例、失败路径、取消、借用有效期和插件卸载约束与声明一致。
- [ ] 当前并非完整无异常运行矩阵或稳定 C++ ABI 的能力，没有被发布说明扩大承诺。
- [ ] 文档分类、路径、文件名、文件链接与锚点检查通过，性能声明有对应方法与结果。

相关命令以[构建指南](../guides/build.md)、[CI 策略](../guides/ci.md)和
[Linux 清单](linux-validation.md)为准，历史测试次数不是本轮结果。

## 制品与发布

- [ ] 源码包含下载型开发依赖时，清单、联网冷配置、预填缓存离线配置及用户准备说明已验证。
- [ ] 源码归档对应固定标签；如交付 SDK，干净构建、安装与 consumer 验证覆盖同一批字节。
- [ ] SDK 明确平台、架构、编译器、CRT、链接模式、配置及异常/RTTI；源码发布不伪称含预编译包。
- [ ] 所交付文件集、SHA-256、来源 SHA 和构建环境可追溯；不包含开发机临时文件或错误 runtime。
- [ ] 发布前门槛全部完成；Release 的 tag 指向已验收 SHA，说明与范围、变更记录和限制一致。
- [ ] 发布后从实际入口重新下载并核对；Record 保存公开链接、校验结果与最终发布状态。
- [ ] 失败时保留证据；不绕过失败、不移动已公开标签、不静默替换已公开制品。

不适用项必须写明原因；阻塞项不得简单删掉或改勾选为已通过。
