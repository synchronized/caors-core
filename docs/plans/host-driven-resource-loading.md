## 已确认的职责边界

宿主拥有文件、网络、数据库、下载缓存、鉴权、重试、执行环境及实际操作清理。
宿主 loader 取得数据、解析、请求必要依赖并创建对象，最后向资源核心交付结果。
资源核心负责资源键索引、类型化句柄、缓存、在途请求合并、依赖等待、错误传播与重载发布。
JSON 等格式转换只接受已有文本或字节，不自行打开文件或发起网络请求。

```text
宿主文件／网络／数据库 → 宿主 loader → 解析与创建对象
                              │              │
                              └→ 资源核心请求依赖
                                             ↓
资源核心：身份索引、请求共享、依赖等待、缓存、句柄、重载发布
```

最终移除 CAORS 文件 IO 子系统及文件装配桥。构建过程中允许暂存明确标记的迁移适配，
最终不以另造等价文件服务或长期转发头完成名义上的删除。
资源核心可以选用，已有完整资源系统的下游无需启用它。

## 资源键、对象身份与持久化

- 运行期对象 ID 标识对象实例，不充当默认持久资源键；重载的新旧对象可以有不同对象 ID。
- 资源键由宿主选择，支持拥有式路径字符串、GUID 或自定义组合键；不强制转为 GUID。
- 键提供稳定的相等比较及哈希；哈希仅用于索引，不能以有限位哈希替代完整键并忽略碰撞。
- 键包含影响共享结果的语义，例如来源域、子资源、sRGB/线性选项；索引还区分资源类型。
- 路径大小写、规范化、URL 查询参数、重命名及别名策略由宿主制定，CAORS 不自动按文件路径解释字符串。
- 加载操作和缓存拥有需要保留的键，不借用短寿命 string_view；键在索引期间不可变。
- 资源对象无需继承保存 GUID 的基类；引用序列化保存宿主资源键，不保存运行期地址或句柄版本。
- 使用同一逻辑键时，普通加载共享当前在途操作；显式重载形成独立加载代次，不能错误合并到旧代次。

推荐先验证 manager/cache/ref 按 Key 模板化的可行性，默认路径示例使用 std::string，GUID 仍可选。
异构依赖在同一 manager 的键策略下组合类型信息；是否需要键类型擦除、分配器感知字符串和自定义
Hash/Equal 参数在第一批定稿。避免同时引入模板管理器和另一套通用键容器。

## 异步 loader 与生命周期

start 发起后返回，成功表示接受操作；完成凭证可移入宿主回调或协程状态，在任意后续时刻交付结果。
启动拒绝不能继续保留凭证操作；接受后必须交付或销毁凭证以形成可观察终态，重复交付不能重复发布。
保留现有一次性交付、提前完成握手与错误诊断语义，重构时用对应回归约束。
上下文保留资源键、结果分配器、协作取消、进度、必要调度和可选通用批次数据，不含文件来源类型。
宿主已有调度时不要求另开线程池；worker 表示调度能力，不代表网络传输必须占用 worker。

网络完成后可以直接创建对象，也可以将解析和主线程对象创建分别投递到宿主执行器。
用户通知和缓存发布须有明确执行器契约，拒绝或丢弃任务也要终态收尾，不能永久 pending。
取消仅表示请求停止；分配器、网络缓冲、宿主循环和模块代码必须覆盖真实操作及迟到回调的清理。
管理器停止接收新操作后，在途状态的寿命与关闭策略须显式定义，禁止回调访问已析构管理器。

## 动态依赖与完成规则

主要验收场景为：场景下载解析后发现预制体，预制体解析后发现材质，材质再发现纹理。
独立纹理请求并行；共享纹理只启动一次实际加载。全部必需依赖成功后，父 loader 才交付成功对象。
可选依赖的占位或降级由父 loader 明确处理，不能吞掉必需依赖错误。

依赖请求必须通过关联当前操作的加载上下文进入核心，自动登记父子操作关系；不能仅裸调管理器后
阻塞等待。推荐先实现回调式继续执行和组合等待，再添加可选协程适配，两者复用同一状态机。
不得在单线程事件循环或有限 worker 中阻塞等待子请求，也不得通过递归同步回调无限增长调用栈。

图节点区分 manager、资源类型、资源键和加载代次。依赖边发布与循环检查必须在请求共享的图上协调，
能诊断多个并发根形成的 A → B → A 环，不能只检查某个递归调用栈。
深度、节点数和并发操作的限制可配置；达到限制须报告错误并清理，不形成无界请求风暴。
父请求持有子资源所需句柄直到构造完成，最终对象是否继续持有依赖由其类型和宿主决定。
运行期加载等待图与持久依赖元数据分开，操作清理后不能永久残留等待边。

取消一个父订阅只撤销该订阅的需求；仍被其他父节点或外部请求使用的子操作继续执行。
仅在没有剩余需求时才向共享底层操作请求停止；终态、取消和迟到完成竞争必须只裁决一次。
父失败后释放其余依赖订阅，保留能定位父子资源键的错误原因；独立已完成缓存无需回滚。
默认就绪状态表示必需依赖完整可用；渐进显示、部分就绪与流式细节作为后续独立扩展。

## 缓存与重载

相同类型与语义键的普通并发请求共享一次加载，缓存命中直接返回已有句柄。
保留旧句柄在重载后独立有效的语义；加载新对象期间不清空当前成功缓存。
最新有效重载代次决定默认绑定，较早完成不能覆盖新结果，失败不得破坏当前成功缓存。
父加载使用已获得的依赖句柄，不在发布时重新查询并悄悄替换依赖。
默认不承诺场景及全部子资源属于同一服务端修订；需要一致版本时由宿主把版本加入键或通用批次快照。
依赖重载默认不自动递归重载所有父资源；级联策略、版本锁定和事务发布另行定义。

## 拟议使用方式

以下为方向示意，类型名、错误和组合接口待原型定稿，不作为可编译示例或当前 API 文档：

```cpp
resource_manager<std::string> assets{execution};
assets.register_loader<scene>(scene_loader);
auto request = assets.request_load<scene>("scenes/main.scene");
```

宿主 scene_loader 异步下载并解析，使用当前上下文请求预制体依赖；依赖完成后创建 scene 并交付完成凭证。
预制体和材质 loader 使用相同规则。无需注册文件系统、来源表、路径到 GUID 清单或 CAORS 网络后端。

## IO 与装配退出清单

### 整目录删除的硬性目标

用户明确要求最终删除整个 `include/caors/io/` 和 `src/caors/io/` 目录，同时删除公共聚合头
`include/caors/io.h`。本目标不是将 IO 设为可选编译，也不是仅让资源核心不引用 IO。
最终仓库及全新安装包均不得继续提供 CAORS 文件 IO 子系统。

不以改名、迁移目录、转发头、兼容别名或另一套等价文件服务保留原体系。
允许迁移的仅是有独立消费证据的纯数据类型、算法及必要字节协议，例如字节缓冲和内存序列化输出；
逐项记录新归属与调用者，不将文件打开、挂载、网络传输或来源装配带入这些接口。

直接删除当前目录会破坏现有调用，因此实施时须同步迁移或删除资源、序列化、配置、插件清单、
工具、测试、示例和基准的相关消费；这些迁移均属于 P4/P5 的交付范围。
迁移期临时适配必须在 P5 删除，不能以“已解耦”代替整目录删除验收。
当前源码目录尚未删除；整目录删除仍是 P5 的硬性出口。

| 能力 | 迁移后归属与删除条件 |
| --- | --- |
| file_service、backend、同步文件系统、挂载与旧路由 | 宿主 IO；库内消费迁完后删除公共头、实现、目标、样例和安装残留 |
| provider/source、byte_reader、文件来源快照 | 宿主 loader 或临时迁移适配；默认 JSON 与配置消费退出后删除 |
| 项目配置及文件/来源工厂 | 工程策略由下游维护；迁出状态与所有权，再移除 CAORS 内建文件装配 |
| JSON、MessagePack、序列化 | 保留内存数据转换；文件便利函数退出，必要纯字节接口归序列化职责，不重建文件抽象 |
| manifest 的存储位置 | 宿主定位表；核心只取实际需要的类型、版本及依赖元数据 |
| 路径、URI、字节缓冲 | 逐个审计独立消费；需要的纯数据工具迁至合适模块，其余删除，不借 IO 命名继续残留 |
| 插件清单及平台动态库加载 | 清单读取改由宿主提供数据；动态库打开属插件平台职责，不因 IO 退出误删 |

## 验收矩阵

- 模拟可控网络：场景 → 两个预制体 → 材质 → 共享纹理，乱序完成仍正确，只下载一次共享资源。
- 单线程循环：任意阶段延迟完成；父子等待不阻塞；同步立即完成与异步完成均能收尾。
- 身份：路径和 GUID、相同路径不同类型/选项、哈希碰撞、临时字符串、旧引用序列化迁移。
- 依赖：运行期发现多层依赖、菱形共享、直接环及并发根间接环、深度与数量限制。
- 失败：网络/解析/子资源失败，任务拒绝/丢弃，重复完成，冷/热状态分配失败。
- 取消：一个父节点取消不影响其他订阅；最后需求消失请求停止；迟到回调清理和管理器寿命。
- 重载：乱序完成、失败保留旧缓存、旧句柄保活、依赖代次绑定和父操作中途重载。
- 构建：资源核心目标的源码/公共头/链接依赖均不含 IO 与项目装配，独立安装及重定位消费者通过。
- 整目录删除：仓库不存在 include/caors/io/、src/caors/io/ 和 include/caors/io.h；安装公共头中也不存在这些入口。
- 残留：活动源码、构建文件、安装/导出配置、测试、示例和基准不再引用已删 IO 头、源文件或目标；补充公共头不存在的编译检查。
- 迁移边界：逐项复核迁出类型的独立用途，不存在改名复制的文件服务或长期兼容桥；历史记录允许保留旧路径，当前使用文档须更新。
- 平台：本机相关回归，关键并发与生命周期批次 ASan/UBSan 及插件专项，合并前运行受影响平台常规 CI。
- Web：无文件系统假设，模拟宿主网络跨事件循环完成；清理与取消在实际浏览器验证。

可控宿主模拟用于确定性测试；外部真实网络不作为单元测试前提。
原型与平台实际结果写入独立 Record，本计划只更新状态和证据链接。
